# The Psych version matrix

Psych's behaviour is the product of three independently-versioned things: the
Ruby it runs on, the psych gem itself, and the libyaml it links against. A bare
"Psych 5.2.2 does X" claim does not say which of the three produced X.

These images vary **one axis at a time** from a baseline of

    ruby 3.4 / psych 5.2.2 / libyaml 0.2.5

so a difference between two rows is attributable to the one thing that differs
between them. `psych` in the main parser list is that same baseline.

Every Dockerfile here is generated by `generate.rb` from the `COMBOS` table in
`lib/parsers.rb`; edit that table and re-run the script rather than editing a
Dockerfile by hand. They share `emit.rb` with the other Psych images, so the
build context is this directory and each image is built with `-f`.

Combinations that do not exist in the wild are the point, not a bug. Nobody
ships psych 5.2.2 against libyaml 0.2.1; building it is what isolates the C
library as a variable.
